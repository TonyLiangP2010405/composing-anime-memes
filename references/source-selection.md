# 找真实斗图底图

用户要的是**基于真实斗图表情包做换头模板**，不是找现成的空白模板，也不是把 `meme-generator` 内置模板改名字。

## 1. 主力路线：发表情（fabiaoqing.com）

```bash
python scripts/harvest_fabiaoqing.py list   --out /tmp/fbq --pages 4 \
  --keywords 滑稽 滑稽脸 熊猫头 狗头 蘑菇头 拿刀熊猫 拍桌熊猫 滚蛋熊猫
python scripts/harvest_fabiaoqing.py thumbs --out /tmp/fbq
python scripts/harvest_fabiaoqing.py large  --out /tmp/fbq --pick 0 2 3 5
```

接口事实（实测）：

- 结果页：`https://www.fabiaoqing.com/search/bqb/keyword/<关键词>/type/bq/page/<页码>.html`，每页约 15 条；
- 图片属性 `data-original`，`/bmiddle/` 是预览，换成 `/large/` 拿原图；
- 发表情对普通 `requests` 会 SSL 握手失败，抓页面必须走 `curl`（脚本已处理）；图片 CDN `img.soutula.com` 用 requests 正常；
- 同一个词短时间反复请求会返回空页，脚本内置退避；多关键词之间 sleep 1s。

## 2. 备用路线：斗图啦（doutula.com）

```text
https://www.doutula.com/search?keyword=<关键词>
```

- 结果页里的 `<img src="...">` 直接是 `img.doutupk.com` 的图片，JPG/PNG/GIF 都有；
- 用 `curl -L` + 浏览器 UA 抓页面，正则取 `src`；
- 优先挑 `.gif`，其次 JPG/PNG；缩略图只用于筛选。

## 3. 备用路线：360 图片搜索

```text
https://image.so.com/j?q=<关键词>&src=srp&sn=0&pn=30
```

返回 `list[].img`（原图）、`thumb`、`link`（来源页）、`title`、`width/height`。中文召回好，但有速率限制：连续快速请求会返回空列表，查询之间 sleep 3s 以上，空结果退避 6s 重试。

## 4. 关键词

### 4.1 优先题材（按换头难度排序）

1. **滑稽脸**：黄色圆脸、斜眼笑、大脸特写。边界就是一个圆，脸内没有头发、耳朵、手，最容易盖准。关键词：`滑稽`、`滑稽脸`、`贴吧滑稽`、`滑稽 动图`。
2. **熊猫脸**：熊猫头白色蛋形脸。白脸和黑身体/耳朵对比强，椭圆蒙版天然贴合；优先选单张大脸、脸没有被手/道具挡住的。
3. **狗头 / 蘑菇头**：次选；狗头只收“狗头+大字/身体”的经典梗，注意耳朵、手、字幕不要压在脸上。
4. **真人反应图 / 真人照片：不用。** 肖像和版权风险，脸型也不规整；拿到直接淘汰。
5. **黄摆件 / 沙雕 / 圆形物体：不用。** 检测器会把它们当滑稽脸，换完只剩头像。

**默认先搜滑稽和熊猫头**；这两类找不到合适动图时，再退到狗头/蘑菇头。真人一律不用。

### 4.2 按梗分的关键词

不要只搜“表情包”：

```text
熊猫头：熊猫头 表情包、熊猫头 拿刀、熊猫头 拍桌、熊猫头 滚蛋、熊猫头 指人
狗头：狗头 表情包、狗头 嘲讽、狗头 问号
蘑菇头：蘑菇头 表情包、蘑菇头 问号、蘑菇头 指人
滑稽：滑稽、滑稽脸、贴吧滑稽、斜眼笑、滑稽 动图
动作：拿刀 熊猫、拍桌 熊猫、滚蛋 熊猫、键盘侠 表情包
```

## 5. 筛选标准

1. **是斗图，不是素材**：有熊猫头/狗头/人物脸、有字幕或场景，能在群聊里当反应图。
2. **脸清楚**：脸没有被手、字幕、道具大面积挡住；眼睛/鼻子/嘴/下巴能看清。
3. **分辨率**：短边 ≥ 260 px；太小放大后糊，覆盖检查也不准。
4. **动图**：先确认真是多帧（扩展名 gif ≠ 有动画）；头会动的必须能逐帧跟踪，头静止的最省事。
5. **不是内置模板**：和 `meme-generator` 的 282+ 个 key 对比；不要把 `petpet`、`punch`、`knock` 等内置模板改个名字。
6. **不是空白模板**：昵图、千图、稿定之类的空白 PNG 不要；用户要的是斗图。
7. **不是自己画的插画**：PIL 画的扁平场景不算斗图；用户会直接否掉。
8. **不是真人**：真人照片、真人反应图一律淘汰；只用滑稽脸/熊猫脸/狗头/蘑菇头这类风格化脸。
9. **不是大头特写**：脸框面积占画面 >45% 的，换完容易只剩头像；默认不做。
10. **不是摆件/沙雕/圆形物体**：先看 200 px 缩略图能不能认出是熊猫/滑稽；认不出就换图。

## 6. 记录与版权

- 每个底图记录：原始页面 URL、图片 URL、SHA-256、尺寸、帧数、来源关键词。
- 写进模板的 `meta.json` 或仓库的 `ASSET_SOURCES.md`。
- 素材版权归原作者；默认仅限群内非商业使用。对外分发前先确认授权。

## 7. 不要耗时间的路线

- **Google 图片**：本机实测会被 IP 封到 `sorry/index`；换域名/代理/SearXNG 都被挡。
- **Bing 图片**：接口可用但中文语义匹配差，只在明确作品/品牌名时兜底。
- **百度图片 `acjson`**：对爬虫直接返回 `Forbid spider access`。
- **素材站/设计站**：空白模板，不是斗图。
