# 找素材：中文斗图表情包

用户要的是**基于斗图表情包做模板**，不是"找现成的空白模板素材"。素材站（昵图、素材网、稿定之类的 PNG 空白图）一律不用——那是设计素材，不是斗图。

## 1. 主力路线：发表情（fabiaoqing.com）站内搜索

搜索引擎对中文斗图召回差（搜"电视"会返回家电广告），而斗图站自己的搜索页直接列原图。发表情是验证过最好用的一条：

```bash
# 1) 抓搜索结果索引（关键词可以给很多个，自动去重）
python scripts/harvest_fabiaoqing.py list --out /tmp/fbq --pages 6 \
  --keywords 电视 手机 屏幕 举牌 报纸 白板 相框 圆形

# 2) 下载缩略图（小、快，用来看图筛选）
python scripts/harvest_fabiaoqing.py thumbs --out /tmp/fbq

# 3) 只对选中的编号下载原图
python scripts/harvest_fabiaoqing.py large --out /tmp/fbq --pick 0 2 3 4 8
```

接口事实（实测 2026-11）：

- 结果页：`https://www.fabiaoqing.com/search/bqb/keyword/<关键词>/type/bq/page/<页码>.html`，每页 15 条；
- 图片属性是 `data-original`，`/bmiddle/` 是预览图，把路径换成 `/large/` 拿原图；
- 发表情对普通 `requests` 会 SSL 握手失败，抓页面必须走 `curl`（脚本里已处理）；图片 CDN `img.soutula.com` 用 requests 正常；
- 同一个词短时间反复请求会返回空页，抓取器已内置退避重试；连续抓多个词之间要 sleep 1s 左右；
- 原图常见是 300×250 到 800×800，够做模板；缩略图只用于筛选。

可用关键词（按目标形状分）：

```text
方形/屏幕：电视 看电视 手机 屏幕 电脑 显示器 相框 报纸 白板 举牌 牌子 工牌 证件 广告
圆形：圆形 圆框 镜子 放大镜 钟表 时钟 灯泡 硬币 球 唱片 泡泡 猫眼
```

## 2. 备用路线：360 图片搜索索引

```text
https://image.so.com/j?q=<关键词>&src=srp&correct=&sn=0&pn=30
```

返回 `list[].img`（原图）、`thumb`、`link`（来源页）、`title`、`width/height`。中文召回好，但有速率限制：连续快速请求会返回空列表，查询之间 sleep 3s 以上，返回空时退避 6s 重试。抓到的图片要回到 `link` 页面确认是不是斗图表情包，不能把图床当原作者。

查询词：`熊猫头 表情包`、`沙雕 表情包 斗图`、`表情包 电视`、`表情包 手机 屏幕`、`表情包 放大镜`、`表情包 钟表`。

## 3. 不要指望的路线

- **Google 图片**：本机实测用真 Chrome（持久 profile + 隐藏 `webdriver`）能查到几次，随后 IP 被拉到 `sorry/index` 反爬页；换 `google.com.hk`、translate 代理、公共 SearXNG 实例都被挡。不要在它上面耗时间。
- **Bing 图片**：接口可用但中文语义匹配差（搜"通缉令"返回康奈尔大学海报），只在明确知道作品/品牌名时兜底。
- **百度图片 `acjson` 接口**：对爬虫直接返回 `Forbid spider access`。
- **素材站/设计站**（昵图、千图、稿定）：是空白模板素材，不是斗图，明确不要。

## 4. 筛素材

1. **开口必须被线条完整包围**：描边有缺口、脸压到边框、开口贴图片边缘的丢弃。
2. **形状只收圆形和方形**：正圆（长短轴差 ≤ 8%）、正方/矩形（宽高比 ≤ 1.9）；拟合出椭圆的直接淘汰。
3. **分辨率**：短边 ≥ 260 px；缩略图只能筛选，不能直接做模板。
4. **动图**：先确认真是多帧（扩展名 gif 不等于有动画），再看替换区跨帧平均差；头部/屏幕静止的动图最省事。
5. **内容**：优先有字幕、有场景、头像放进去讲得通的图；"随便一块衣服/墙面"不算替换区。

## 5. 归属

- 保留来源页面 URL、原图直链、尺寸、SHA-256，写进素材来源文档；
- 表情包版权归原作者，仓库仅用于群内非商业斗图；公开发布前自行确认授权；
- 不要用带明显商业水印、付费素材站、需要登录才能看的图。

## 6. 淘汰标准

- 开口没有闭合（脸和背景连成一片）→ 检测必然失败，换图；
- 开口被文字、手、道具压住一半 → box 再准也会露残边；
- 拼贴/二改/带截屏边框 → 开口里外都是噪点；
- 动图里整张画布在抖 → 头像固定会露馅；
- 同一张图改色、镜像、裁切不算新素材。
