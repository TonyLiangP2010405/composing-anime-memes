# 标准图形模板：几何与参数

替换区是原图里**已经画出来的一块规整开口**，只接受**圆形**和**方形/圆角方形**。模板只需要记录"这是什么形状 + 开口在哪"，渲染器负责抗锯齿蒙版与合成。

椭圆（蛋形）一律淘汰：按脸型拟合的椭圆在聊天尺寸下会读成"贴上去的一坨"，这是本项目已被用户否掉的方案。

## 1. 量开口

### 1.1 深色线条围出的开口（绝大多数斗图表情）

熊猫头、蘑菇头、电视屏幕、手机屏幕、报纸照片框都有一个共同结构：**深色线条围出一块亮区**。做法是：

**只取圆形和方形**：孔洞拟合的结果分三档——接近正圆（长短轴差 ≤ 8%）记 `circle`；最小外接矩形接近正方（宽高比 ≤ 1.15）记 `square`；其余（含椭圆）丢弃。矩形屏幕允许宽高比 ≤ 1.9，用 `rect`。

1. 灰度图取阈值 `gray < 85` 得到深色蒙版；
2. 形态学闭运算（9×9）把描边上的小缺口补上；
3. `cv2.findContours(..., RETR_CCOMP)`，取"孔洞"轮廓（即外轮廓的子轮廓）；
4. 孔洞面积在整图 3%–62% 之间，再分别拟合：
   - 圆形：`cv2.fitEllipse`，`fit = area / (π·a·b) > 0.93`，长短轴差 ≤ 8% → `shape: circle`；
   - 方形：`cv2.minAreaRect`，`fill = area / (w·h) > 0.93`，宽高比 ≤ 1.15 → `shape: square`；
   - 矩形：同上但宽高比 ≤ 1.9 → `shape: rect`（电视机、手机屏幕）；
5. 圆形 box = `[cx - r, cy - r, 2r, 2r]`；方形/矩形 box = 最小外接矩形的左上角与宽高。

项目里的实现：`tools/slot_detect.py`（检测：`detect` 孔洞、`panels` 亮面板、`rings` 圆环、`discs` 色块圆）+ `tools/review_slots.py`（批量出带标注的总览图）。**必须看标注图复核**：拟合出的圆可能比原图开口大 1–2 px，压到描边/镜框。

### 1.2 手工量 box

开口不是深色线条围出来的（浅色边框、贴图、圆角卡片），用工具 `author_slot.py scan` 出候选，再手工微调 `box`，然后重新渲染对照。手工值同样要落进 `scenes.json`，**不允许在渲染器里按比例猜**。

## 2. 参数

| 参数 | 默认 | 什么时候用 |
|---|---|---|
| `shape` | `ellipse` | 按开口选 `ellipse` / `circle` / `rect` / `roundrect` / `polygon` |
| `box` | 必填 | `[x, y, w, h]`，源图像素；越界会被裁掉、形状变形 |
| `zoom` | 1.0 | 熊猫头类 1.12–1.20，把头像的头发、衣领推出替换区；屏幕类 1.0 |
| `anchor` | 0.45 | `cover` 缩放后保留头像上部（脸通常偏上）；`0.5` 居中 |
| `feather` | 1.0 | 屏幕/相框 1.2–1.6 更柔和；熊猫头 1.0 保持边缘利落 |
| `depth` | 无 | 屏幕、手机、相框：`{"width": 4, "strength": 0.35}` 让头像像"嵌进去" |
| `ring` | 无 | 原图没有描边时补一圈边：`{"width": 2, "colour": [28, 28, 28]}` |
| `boxes` | 无 | 动图里脸会动时逐帧给 box；头部静止的动图用单 `box` |

## 3. 三个已验证形态

**圆形开口（镜头、表盘、灯泡、硬币、圆徽章）**
正圆，`shape: circle`，box 为外接正方。`zoom` 1.02–1.08 让脸填满圆；`feather` 1.0–1.2。检测优先用 `rings`（镜框边缘比内外都暗/艳）或 `discs`（实心色块圆）。

**圆形不要吃的坑**：拟合半径偏大会盖住镜框金属边，出现一圈断口；偏小会留一圈白边，读成贴纸。

**手机屏幕 / 电视（矩形）**
`box` 贴屏幕内沿，`depth` 加 4 px 内阴影做出玻璃厚度，`feather` 1.2。注意屏幕四角若有圆角，改用 `roundrect` 并把 `radius` 设成实际圆角。

**来电界面的头像位（圆角矩形）**
小尺寸（350 px 左右）也要保证 `box` 精确；圆角半径按原图取，`feather` 1.4 避免边缘生硬。

## 4. 动图

斗图动图多数是"头部静止 + 手臂/背景在动"，这类直接复用单 `box`：

- 用 `motion`（替换区跨帧平均绝对差）筛素材，> 100 说明脸在动；
- 头部静止但手臂穿进替换区时，手臂会被头像盖住，属可接受（原片里手臂在脸前的情况要改用前景层，本项目不做）；
- 只有头部确实位移时才写 `boxes`（逐帧 box），并且每帧都要目视核对。

GIF 编码：共用调色板（从 10 帧抽样生成）+ `disposal=2` + `optimize=False`，避免逐帧调色板导致的闪烁。Pillow 会把内容完全相同的相邻帧合并，所以输出帧数可能小于源帧数，时长累计不变。

## 5. 失败模式对照

| 现象 | 原因 | 修法 |
|---|---|---|
| 替换区边缘出现黑色缺口 | box 压到原图描边 | box 内缩 1–2 px |
| 头像周围一圈白月牙 | box 小于原图白区 | box 放大到白区边界；或加 `feather` 过渡 |
| 头像看起来浮在脸上 | 头像整张进入替换区（含头发/衣领） | `zoom` 提到 1.15+，或换更"只有脸"的头像裁切 |
| 屏幕没有厚度、像贴纸 | 缺内阴影 | `depth` 打开 |
| 动图闪、残影 | 逐帧 box 抖动或调色板逐帧变化 | 固定单 box，共用调色板 |
| 输出帧数变少 | Pillow 合并了相同帧 | 正常，检查时长累计即可 |
