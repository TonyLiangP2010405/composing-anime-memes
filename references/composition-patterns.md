# 构图模式与必要资产

## 快速选择

| 问题 | 模式 | `actors[].shape` |
|---|---|---|
| 头像是否代替玩偶、抱枕或动作中的角色？ | `character` | `target_mask` |
| 头像是否就是杯身、衣物或包装上的印刷图案？ | `print` | `surface_mask` |
| 画面是否本来就在展示照片、书页、相框或方形绘画？ | `photo` | `quad_fill` |
| 目标是否为黑板粉笔画？ | `chalk` | `target_mask` |
| 是否无法说清头像与动作的关系，或目标一直看不清？ | `reject` | 不适用 |

`shape` 描述目标，不描述输入头像。禁止把 `circle`、`ellipse` 或统一头像轮廓当作默认值。

## 蒙版与填充语义

蒙版是与 `source_size` 相同的灰度图：**白色显示头像，黑色保留原片，灰色只用于边缘过渡。** 角色和印花的蒙版必须同时包含有效白色区域和保留原片的黑色区域，不能用全白图覆盖整帧。

- `target_mask`：从目标脸部、头部或粉笔画轮廓取得形状，而非从输入头像裁圆形。
- `surface_mask`：从杯身、衣物或包装的实际印花区域取得形状，并保留曲面、纹理和明暗。
- `quad_fill`：不使用圆形蒙版；头像填满四个顶点定义的实际方形或透视四边形。

静止目标在所有帧复用蒙版或四边形。运动目标只标必要关键帧并插值，插值穿帮时才增加单帧修正。

## `character` + `target_mask`

必要资产：

- 每个 actor 的头像索引、`shape: "target_mask"` 和角色身份。
- 原角色脸部或头部的非矩形轮廓；不能使用圆形或矩形照片排版。
- 原角色需要保留的耳朵、头发、蝴蝶结、身体、牙齿、手臂等前景。
- 目标轨迹、允许变化蒙版和必要的逐帧目标蒙版。
- 多人各自独立的区域；同一输入变化不得改写另一角色。

完整配置见 `examples/character_scene.json`。关键字段：

- `mode`、`reference_index`、`image_count`、`source_size`。
- `actors[].image/shape/change_mask`。
- `actors[].frames[].index/quad/mask`：位置、透视和目标轮廓。

张口、进入画面等动作应使用场景参考帧，不是机械取 GIF 中点。跟踪不稳定时使用人工关键帧插值或缩短片段；仍不稳定则 `reject`。

## `print` + `surface_mask`

- 蒙版轮廓就是杯身、衣物或包装的印花区域，不是圆形头像或矩形白底。
- 头像填满该区域，并通过四边形、网格或 UV 贴合曲面。
- 保留原物体褶皱、纹理、高光和环境色；手、杯口、头发和缝线保持在上层。
- 印花颜色与对比度必须足以辨认，不能用低透明度把头像洗没。

## `photo` + `quad_fill`

- 头像填满实际四边形；方形画布和照片不使用圆形裁剪。
- 保留真实纸边、画布边缘和纸张底色，随页面透视、弯曲和环境光变化。
- 手指和头发必须在照片上方；多人照片不得互相串色。

## `chalk` + `target_mask`

- 使用亮度与边缘提取可辨认轮廓，在目标区域内变成线条。
- 白色背景不得生成矩形底板；保留黑板颗粒、板擦痕迹和原角色前景。
- 清除边缘检测产生的人工图像外框。

## `reject`：不适合制作

出现以下任一情况时，淘汰、换素材或明确留为待修：

- 头像最终尺寸小到无法辨认。
- 无法解释头像和场景动作的关系。
- 跟踪漂移、频繁穿帮或遮挡无法可靠标注。
- 必须强行拉伸、放大或降低清晰度才能掩盖问题。

`reject` 必须写 `reason`，不得带正式视觉审批。
