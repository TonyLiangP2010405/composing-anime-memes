# 换头模板：脸框、尺寸与逐帧跟随

## 1. 脸框不是头框

换头要盖的是**原图的脸**，不是整个头。熊猫头的耳朵、身体、菜刀、字幕都不应该决定头像中心。

| 底图 | 脸框 | 不该用的中心 |
|---|---|---|
| 跳舞熊猫 | 白色脸/人脸的矩形 | 两只黑耳朵的中点、身体中心 |
| 拿刀熊猫 | 白色脸/人脸的矩形 | 熊猫头外轮廓、菜刀 |
| 滚蛋熊猫 | 白色脸/人脸的矩形 | 红脸颊外沿、蛋 |
| 鲁迅问号 | 人脸矩形（含下巴/额头） | 整张照片、头发中心 |
| 熊猫头特写 | 人脸/白脸区域 | 整张画布中心（如果脸偏） |

**判定**：把脸框画在底图上，框里应该只有眼睛、鼻子、嘴、脸颊、下巴、额头；框外是耳朵、头发、身体、道具。

## 2. 量脸框

### 2.1 真人脸 / 鲁迅

```python
import cv2
cascade = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")
faces = cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30))
```

- Haar 的框通常只到眉毛/嘴，**向外扩 10–20%** 才能盖住下巴和额头。
- 检测不到时不要硬猜；用网格图手动量，再跑覆盖检查。

### 2.2 熊猫头 / 风格化脸

- 先用网格图给出首帧脸框（例如 `(80, 22, 100, 100)`）。
- 用 `scripts/track_heads.py` 做光流跟踪，输出每帧中心。
- 不要用整张脸的模板匹配：熊猫脸的表情/颜色会变，匹配会跳到耳朵、身体或背景上。光流跟眼睛/鼻子/嘴的特征点更稳。

### 2.3 动图判断

抽首/中/尾帧，比较脸中心：

- 位移 ≤ 3 px：可以固定中心。
- 位移 > 3 px：必须逐帧 `HEAD_CENTERS`。
- 头有明显旋转/缩放：在中心之外再补 `angle` / `scale`；只做平移会看起来“贴着脸滑”。

## 3. 头像尺寸

圆形要覆盖矩形脸框的四个角。设脸框宽 `w`、高 `h`，最小直径：

```text
D_min = sqrt(w² + h²)
```

| 脸框 | D_min | 建议 |
|---|---:|---:|
| 100×110 | 148.7 | 154–158（示例 156；150 只剩 0.67 px 余量） |
| 110×110 | 155.6 | 160–162 |
| 90×100 | 134.5 | 138–142 |
| 186×186（2× 画布） | 263.0 | 266–270 全盖；只盖中央脸 210 会露下巴/额头 |
| 600×584 | 837（按矩形算） | 特写脸是椭圆，600 圆基本盖满画布 |

**D_min 只是理论值，实际再加 3–5 px 余量**：光流中心有 1–2 px 抖动，`paste_center` 还会 `int()` 截断；卡在 D_min 上会周期性露边。

**常见错误**：用 `D = max(w, h)` 或 `D = w`。这样只盖住脸的中部，四个角（脸颊、下巴、额头）会露出来，用户会直接说“没把脸覆盖上”。

### 3.1 保留熊猫耳朵：椭圆蒙版

大圆盖脸会把熊猫耳朵一起盖掉。如果用户要保留耳朵：

- 椭圆宽 = 脸框宽 × 1.05–1.1；
- 椭圆高 = 脸框高 × 1.05–1.1；
- 椭圆中心 = 脸框中心；
- 用椭圆 mask 裁头像，再贴到原图；耳朵在椭圆外，自然保留。

椭圆蒙版不是“描脸”，它是按脸框的几何椭圆；不要沿发际线/下颌勾不规则轮廓。

**椭圆盖不住矩形四角**：同中心、同比例的椭圆要覆盖脸框四角，需要放大到 `√2 ≈ 1.42×`（因为 `2/k² ≤ 1`）。1.05–1.1× 的椭圆只能保证盖住脸型中央；四角通常是耳朵/背景，但如果用户要求连脸颊/下巴/额头都盖住，椭圆就会大到盖住耳朵——这时直接用大圆。`check_coverage.py --shape ellipse` 只检查内切 70% 脸框，输出 `COVERED (ELLIPSE)`，必须配合视觉初审。

### 3.2 头像内部

- 头像先 `square()`，再按目标尺寸缩放；不要拉伸成椭圆，除非使用椭圆蒙版时接受轻微变形。
- 头像自带的背景会填满圆/椭圆，这是正常的（QQ 头像本身有背景）。
- 如果用户要求“只露脸”，先按亮度梯度能量图裁脸，再 cover 缩放；不要直接把整张半身照塞进去。

## 4. 逐帧中心

`scripts/track_heads.py` 的做法：

1. 在首帧脸框内取 `goodFeaturesToTrack`（眼睛、鼻子、嘴、边缘）；
2. 用 `calcOpticalFlowPyrLK` 逐帧跟踪这些点；
3. 取位移的中位数，累加到脸中心；
4. 对异常大跳变做 clamp，输出 `HEAD_CENTERS` 和可视化。

模板里**硬编码**中心，不依赖 OpenCV：

```python
HEAD_CENTERS = [(130, 72), (133, 76), ...]

source = load_frames(base)
center_list = [HEAD_CENTERS] if isinstance(HEAD_CENTERS, tuple) else HEAD_CENTERS
if len(center_list) == 1:
    centers = center_list * len(source)   # 静态脸：一个中心复用
elif len(center_list) == len(source):
    centers = center_list
else:
    raise ValueError(f"{len(source)} frames vs {len(center_list)} centers")

for index, frame in enumerate(source):
    paste_center(frame, head, centers[index])
```

如果原 GIF 帧数和 `HEAD_CENTERS` 不一致，先检查是不是 GIF 编码合并了相同帧；不要用 `index % len()` 把错误藏起来。

## 5. 覆盖检查

`scripts/check_coverage.py --meta meta.json` 直接读模板的 `face_box`、`avatar_size`、`centers`、`shape`，并按 `centers` 把首帧脸框平移到当前帧；也可以手传 `--file/--box/--size/--center`。它做两件事：

1. 在底图上画脸框（绿）和头像圆/椭圆（红），保存诊断图；
2. 计算脸框四角是否都在头像形状内，输出 `COVERED` / `NOT COVERED` 和最小直径。

圆覆盖矩形四角的判据：

```text
distance(corner, center) <= D / 2  for all 4 corners
```

椭圆覆盖：

```text
((x - cx) / (W/2))² + ((y - cy) / (H/2))² <= 1
```

**不要只看首帧**。动图至少检查首/中/尾 + 位移最大的一帧；头像必须始终盖住脸，且跟着脸走。

## 6. 常见失败对照

| 现象 | 原因 | 修法 |
|---|---|---|
| 原脸脸颊/下巴露一圈 | 头像直径 = 脸宽 | 用 `sqrt(w²+h²)` + 3–5 px |
| 头像偏到耳朵/身体 | 用了头框中心 | 用脸框中心 |
| 动图里头像不动 | 固定一个坐标 | `HEAD_CENTERS` 逐帧 |
| 头像跟着脸但边缘闪烁 | 中心抖动/尺寸不一致 | 平滑中心、固定尺寸 |
| 熊猫耳朵被盖掉 | 大圆盖脸 | 换椭圆蒙版 |
| 鲁迅脸没盖全 | 检测框偏小/中心偏 | 检测框外扩 + 重算中心 |
| 头像盖住菜刀/字幕 | 头像太大或中心偏 | 缩小/移动，只盖脸 |
